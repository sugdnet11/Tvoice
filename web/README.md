# Tvoice Web PWA

PWA-клиент Tvoice для iPhone, iPad и современных настольных браузеров. Устанавливается с сайта на главный экран без App Store.

## Реализовано

- единая авторизация через существующий чат API и учётные данные FreePBX;
- контакты, диалоги, сообщения, вложения и статусы доставки/прочтения;
- realtime-события через WebSocket;
- аудио- и видеозвонки через существующий LiveKit;
- завершение звонка на обеих сторонах, таймер, микрофон, камера, динамик и переключение камер;
- перемещаемое локальное превью камеры;
- локальная история звонков;
- системная светлая/тёмная тема;
- web manifest, service worker, offline shell и подготовка Web Push;
- адаптивный интерфейс для iPhone и десктопа.

## Локальный запуск

Требуются Node.js 22.13+ и pnpm.

```bash
pnpm install
pnpm dev
```

## Переменные окружения

Скопируйте `.env.example` в `.env.local`. Пароли пользователей, ключ LiveKit и другие серверные секреты нельзя размещать в браузерных переменных.

| Переменная | Назначение |
|---|---|
| `TVOICE_API_BASE_URL` | Серверный HTTP API чата, по умолчанию `https://chat.185-177-2-115.sslip.io/v1` |
| `TVOICE_WS_URL` | Публичный WSS realtime endpoint |
| `TVOICE_SIP_WSS_URL` | Будущий WSS endpoint FreePBX для нативного браузерного SIP |
| `TVOICE_PUSH_PUBLIC_KEY` | Публичный VAPID-ключ Web Push |

## iPhone

1. Откройте HTTPS-адрес Tvoice в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Откройте Tvoice с созданного значка и разрешите уведомления.

Web Push на iOS требует установленную на главный экран PWA. Для доставки входящих звонков при полностью закрытой PWA сервер должен реализовать `/v1/push/subscriptions` и отправку видимых push-уведомлений.

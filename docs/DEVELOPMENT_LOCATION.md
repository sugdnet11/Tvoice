# Tvoice development location

Primary repository:

`D:\разработки\Tvoice`

Flutter/Windows-compatible path (same files through a junction):

`D:\Tvoice-dev\Tvoice`

Supporting directories:

- `D:\разработки\Tools` — Flutter, Android SDK, JDK and local build caches.
- `D:\разработки\Artifacts` — latest verified APK and Windows release ZIP.
- `D:\разработки\Tvoice\releases\source-snapshots` — immutable Android,
  iOS and Windows source snapshots.

Do not create a second copy for builds. Open the project through
`D:\Tvoice-dev\Tvoice` whenever Flutter or Dart tools are used.

# Tvoice development location

Primary repository for all further Tvoice work:

`D:\Development\Tvoice`

Supporting paths:

- `D:\Development\Tools\flutter` — Flutter SDK;
- `D:\Development\Tools\android-sdk` — Android SDK;
- `D:\Development\Tvoice-stage-a-2026-08-25` — read-only access path to the
  Stage A backup and audit files.

The old repository under `D:\разработки\Tvoice` is preserved as an archive
during Stage A. Do not use it for new builds and do not delete it until the
owner explicitly confirms Stage B cleanup.

Using the English path avoids Flutter, Gradle, CMake and Dart analysis failures
caused by non-ASCII Windows paths.

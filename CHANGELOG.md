# Changelog

## 0.17.11+33 — 2026-08-26

- добавлен отдельный Android-раздел «Конференции»;
- реализованы постоянные комнаты: создание без автоматического входа, повторный вход, копирование и системная отправка ссылки, аннулирование комнаты;
- добавлена обработка ссылок `tvoice://conference/join`;
- реализована адаптивная видеосетка без прокрутки для групповых конференций;
- сохранён режим «собеседник на весь экран + перемещаемое локальное окно» для звонков один на один;
- добавлено завершение экрана конференции при удалении комнаты на сервере;
- добавлены тесты API комнат и разбора ссылок приглашения.

## 0.17.10+32 — 2026-08-25

- подготовлена чистая Android-база из последнего общего Flutter-клиента;
- сохранён интерфейс Android линейки 0.17.3;
- включены SIP/UDP, RTP/G.711, чат, история, видеозвонки и конференции;
- сохранён `applicationId` `tj.tvoice.app`;
- `versionCode` увеличен до 32;
- добавлена воспроизводимая CI-сборка без хранения ключей в Git.

# 0.18.0+34

- Добавлен выбор подключённой компании по корпоративному коду или deep link.
- Одна проверка SIP-данных автоматически авторизует чат и видеозвонки Tvoice.
- SIP-хост и порт теперь загружаются из защищённого профиля компании.
- Сессия сохраняет tenant компании и восстанавливает правильный SIP-профиль.
